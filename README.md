# 👨‍💻 Antonio Acosta - Personal Portfolio

A modern, responsive personal portfolio website developed using HTML, CSS, and JavaScript. This project showcases my personal profile, technical skills, education, projects, certificates, and contact information. It is hosted using GitHub Pages and integrated with Supabase for cloud database functionality.

## 🌐 Live Website

https://aceacosta579-code.github.io/personal-portfolio/

## 📂 GitHub Repository

https://github.com/aceacosta579-code/personal-portfolio

---

# 📌 Project Description

This portfolio serves as my professional online profile. It demonstrates my front-end development skills and showcases projects, achievements, and personal information. The website includes interactive features and a cloud-connected contact form that stores messages in a Supabase database.

---

# ✨ Features

- Responsive Design
- Modern User Interface
- Dark Mode
- Typing Animation
- Animated Skill Bars
- Scroll Progress Bar
- Back to Top Button
- Image Gallery with Preview
- Random Quote Generator
- Live Clock and Date
- Visitor Counter
- Downloadable Resume (CV)

- Cloud Database Integration using Supabase

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/aceacosta579-code/personal-portfolio.git
```

Open the project folder

```bash
cd personal-portfolio
```

Open `index.html` using your browser or Live Server.

---

# 📦 Database

This project uses **Supabase** as its cloud backend.

The contact form stores:

- Name
- Email
- Subject
- Message

inside the **messages** table.
